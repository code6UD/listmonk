🎯 Interface de Ciblage Géographique pour Listmonk

Installation

Glissez ce lien dans votre barre de favoris :

🎯 Ciblage Géo

Instructions d'utilisation :

  1. Glissez le lien ci-dessus dans votre barre de favoris
  2. Allez sur votre interface Listmonk : http://localhost:9000
  3. Naviguez vers la page "Abonnés"
  4. Cliquez sur le favori "🎯 Ciblage Géo" que vous venez d'ajouter
  5. Un bouton flottant "🎯 Ciblage Géo" apparaîtra en haut à droite
  6. Cliquez dessus pour ouvrir l'interface de ciblage géographique

Fonctionnalités

  • 🗺️ Sélection par département : Choisissez un ou plusieurs départements français
  • 🏙️ Filtres rapides par région : Île-de-France, PACA, Occitanie, etc.
  • 👥 Filtrage par population : Définissez des seuils de population minimum et maximum
  • 📊 Aperçu en temps réel : Voyez le nombre estimé de communes correspondantes
  • ✅ Application directe : Les filtres s'appliquent automatiquement dans Listmonk

Exemples d'utilisation

  • Campagne régionale : Sélectionnez "Île-de-France" pour cibler toutes les communes d'IDF
  • Petites communes : Filtrez par population < 2000 habitants
  • Grandes villes : Filtrez par population > 50000 habitants
  • Département spécifique : Sélectionnez uniquement le département 75 (Paris)
✅ Système opérationnel !
