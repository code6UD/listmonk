📋 Comment utiliser ces requêtes dans Listmonk

  1. Cliquez sur un bouton de ciblage ci-dessus
  2. Copiez la requête SQL générée
  3. Allez dans Listmonk → Campagnes → Nouvelle campagne
  4. Dans la section "Listes", cliquez sur "Requête avancée"
  5. Collez la requête SQL dans le champ qui apparaît
  6. Cliquez sur "Aperçu" pour voir le nombre de destinataires
  7. Continuez la création de votre campagne
