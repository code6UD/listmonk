## 🎯 Activation du Ciblage Géographique

### Méthode 1 : Bookmarklet (Recommandée)
1. **Ouvrez** `bookmarklet.html` dans votre navigateur
2. **Glissez** le lien "🎯 Ciblage Géo" dans votre barre de favoris
3. **Allez** sur http://localhost:9000
4. **Connectez-vous** à l'interface d'administration
5. **Naviguez** vers "Abonnés" ou "Subscribers"
6. **Cliquez** sur le favori "🎯 Ciblage Géo"
7. **Utilisez** le bouton flottant qui apparaît !

### Méthode 2 : Script Direct
Le script est accessible à : http://localhost:9000/public/geo-targeting.js
